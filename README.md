# Hospital Management Database

A MySQL database project for managing hospital-related information.

## Contents

This project contains SQL queries for:

- Physicians
- Departments
- Patients
- Nurses
- Rooms
- Procedures
- Medications
- Appointments
- Patient stays
- Prescriptions
- Physician affiliations
- Physician training
- On-call information
- Procedures undergone by patients

## Technologies Used

- MySQL
- MySQL Workbench
- SQL

## SQL Concepts Used

- SELECT
- JOIN
- GROUP BY
- Subqueries
- Views
- Triggers
- UPDATE
- Aggregate functions
- Window functions / RANK

## File

`hospital_management.sql` contains the SQL queries and database operations for the project.
